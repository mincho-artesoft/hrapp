# Everything here is a public marketing site. There is nothing to hide from a
# crawler and no admin surface, so the only rules are the ones that stop bots
# wasting their budget on files that are not pages.
#
# Note: do not disallow /app-ads.txt or the JS/CSS bundles. AdMob's crawler
# obeys robots.txt, so a disallowed /app-ads.txt fails app authorization.
#
# The pages are prerendered now -- every route ships as real HTML, so a crawler
# that never runs JavaScript still sees the words. The bundles stay allowed
# anyway: blocking them makes a page look broken to a renderer that does run
# them, which is a worse signal than the bandwidth is worth.

Allow: /

# Public screenshot renditions are embedded in article and product pages.
