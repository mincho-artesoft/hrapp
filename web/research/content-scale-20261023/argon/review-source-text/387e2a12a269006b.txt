You can also specify how often a calendar event repeats and when it stops repeating. Open Calendar for me Create an all-day or multiday event An event can last all day for one day or multiple days, or start at a specific time on one day and end at a specific time on another day. Go to the Calendar app on your Mac. Click Day, Week, or Month at the top of the Calendar window. Do one of the following: Create an all-day event: In Day or Week view, double-click in the “all-day” section at the top of the calendar. Create an event that spans multiple consecutive days: In the “all-day” section of Week view, drag from the start date to the end date. In Month view, drag from the start date to the end date. Create an event with specific start and end times: In Week view, drag from the start time to the end time. You can drag across multiple days. In Day or Month view, double-click to create an event, then enter the start and end dates and times in the event details. Set up a repeating event Go to the Calendar app on your Mac. Double-click or force click the event to view event details, then click the event’s time. Click the Repeat pop-up menu, then choose an option. To set the event to repeat on a schedule not included in the menu, choose Custom, choose an option from the Frequency pop-up menu, then enter your custom settings. You can also make the event repeat according to a pattern (for example, on the last weekday of each month in which the event occurs). To set up a pattern, select “On the,” then choose options from the pop-up menus. Click the End Repeat pop-up menu, then choose when to stop the event. Modify a repeating event Go to the Calendar app on your Mac. Double-click or force click the event to view event details, then click the event’s time. Click the Repeat pop-up menu, then change the options. Click OK, then click Change. Delete all occurrences of a repeating event Go to the Calendar app on your Mac. Select the first occurrence of a repeating event. Press Delete, then click Delete All. Delete some occurrences of a repeating event Go to the Calendar app on your Mac. Select one or more occurrences of a repeating event. Shift-click to select multiple events. Press Delete, then do one of the following: Delete only the selected event (or events): Click Delete Only This Event (or Delete Only These Events). Delete the selected event (or events) and all future occurrences: Click Delete All Future Events. See also Use reminders in Calendar on Mac Change how you view events in Calendar on Mac Helpful?
