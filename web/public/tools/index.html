Free calendar tools

Create or inspect an ICS file, build a shift roster, or find a meeting time across time zones. Calendar data is processed in your browser.

  • Rotating shift calendar generator

    Build a 90-day Pitman 2-2-3, four-on/four-off or 24/48 firefighter calendar. Preview your duty dates and download an ICS file for Apple Calendar, Google Calendar or Outlook.

  • ICS file viewer and validator

    Open an iCalendar file or paste its text to see event titles, start dates and recurrence rules. Check the file structure before you import it.

  • Merge ICS files and remove duplicate events

    Combine calendars in your browser. Match events by UID and recurrence ID, keep timezone definitions, and download one ICS file.

  • iCalendar recurrence rule generator

    Build an RRULE for a repeating event. Try every other week on Monday, or the last Friday of each month.

  • Three-city meeting time planner

    Find a meeting hour that falls between 08:00 and 18:00 in three cities. Choose a date to account for daylight-saving changes.

  • Working days between two dates

    Count weekdays and weekends, including both dates. Public holidays are counted as ordinary weekdays.

  • Add to calendar link and ICS generator

    Create an event in UTC and get a Google Calendar link, an Outlook.com link and an ICS download for your invitation.

  • ISO week number calculator

    Look up the ISO week and week-year for any date. ISO weeks start on Monday, and week 1 contains the first Thursday.

  • Daily time-blocking calendar builder

    Turn a list of time blocks into calendar events for one day. Enter local start and end times, give each block a name, and download the ICS file.

  • Meeting cost calculator

    Estimate the staff cost of one meeting and of holding it weekly for 50 weeks, using headcount, duration and hourly cost.

  • Five-field cron schedule explainer

    Read a five-field cron expression field by field. Check weekdays, ranges and step values before you schedule a job.

  • Meeting availability in two time zones

    Turn a UTC date and time into a plain-text email line showing both local dates, times and time zones.
