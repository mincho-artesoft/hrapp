Visual time blocking on iPhone: plan a day you can read at a glance

Give appointments, flexible work and breaks distinct names and colours. A short example shows what to put in your calendar and what to move when the day changes.

Set up two calendars you can tell apart

Keep fixed appointments in one calendar and create another for movable blocks. In Apple Calendar, tap Calendars, add the new calendar under your chosen account, then open its information button to choose a colour. Use a word such as “Focus” or “Break” in the title as well. It will still make sense in a small widget or without colour.

Try one morning before planning the week

Try a timed entry if you want a visible start and end. An all-day entry can be useful for a deadline, but it occupies a different part of the day view. For an ADHD-friendly personal setup, choose colours and alert times that you yourself recognise.

Make a reusable copy

In the time-blocking builder, enter a date and one line for each block. Download the ICS file and import it into a separate calendar. If you revise the whole day, remove the earlier import before adding the replacement so the blocks do not appear twice.
