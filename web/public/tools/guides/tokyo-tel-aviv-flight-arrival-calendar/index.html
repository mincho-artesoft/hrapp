Tokyo to Tel Aviv: calculate a flight arrival and save both local dates

Enter departure in Asia/Tokyo and arrival in Asia/Jerusalem. A summer and a winter example show why saving one fixed time difference can put arrival an hour off.

Convert the departure once, then add elapsed time

These examples use an illustrative journey lasting 12 hours 15 minutes. Use the times and connections on your own booking. Tokyo is UTC+9 on both dates. Tel Aviv is UTC+3 in the June example and UTC+2 in November.

Enter the itinerary on iPhone

Create an event for the flight. Select Tokyo for the start and Jerusalem for the arrival zone where the editor offers separate zones. If it uses a single zone for both fields, enter both times in UTC or make two events, one for each airport in its local zone. Check that arrival falls on the following date before sharing it. A device display override changes how you read an event.

Plan the next appointment from the arrival time

For a layover, give each leg its own start and end. Add a separate arrival buffer in the destination zone if you want space before a meeting. In the November example, a 09:00 commitment is 5 hours 15 minutes after the illustrated arrival. Check the date-specific time in the time-zone planner.
