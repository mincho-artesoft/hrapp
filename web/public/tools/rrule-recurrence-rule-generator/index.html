RFC 5545 RRULE Syntax & Recurrence Evaluation Rules

In the iCalendar standard (RFC 5545 Section 3.8.5.3), repeating events are defined by a semicolon-separated RRULE property rather than storing hundreds of individual event copies. Every rule starts with FREQ (DAILY, WEEKLY, MONTHLY, or YEARLY), an optional INTERVAL step (such as INTERVAL=2 for biweekly schedules), and selector parts like BYDAY, BYMONTHDAY, or BYSETPOS.

Order of evaluation matters: FREQ and INTERVAL step through candidate intervals anchored at DTSTART, BY* rules expand or filter days inside each interval, and COUNT or UNTIL bounds the series. Note that RFC 5545 forbids specifying both COUNT and UNTIL in the same RRULE—doing so causes Google Calendar and CalDAV servers to reject the event.

Building Valid Recurrence Rules for Calendar Feeds & APIs

  1. Select the base Frequency (DAILY, WEEKLY, MONTHLY, or YEARLY) and set Interval (1 = every period, 2 = every other period, 4 = every fourth period).
  2. Enter RFC 5545 two-letter weekday codes in BYDAY: MO, TU, WE, TH, FR, SA, SU. For monthly relative positions, prefix the weekday with an ordinal integer—for example, 1MO for the first Monday of the month, 3TH for the third Thursday, or -1FR for the last Friday of the month.
  3. Set COUNT to cap the total number of occurrences (or set 0 to omit COUNT for an open-ended series).
  4. Copy the generated RRULE line into your VEVENT block immediately below DTSTART and validate the complete file in our ICS Validator.

Common RRULE Pitfalls in Apple, Google, and Microsoft Calendars

Always align DTSTART with the first valid occurrence of your RRULE. If DTSTART falls on a Wednesday while RRULE specifies FREQ=WEEKLY;BYDAY=TU,TH, Exchange, Google Calendar, and Apple EventKit can disagree on whether the initial Wednesday counts toward COUNT.

For biweekly schedules (FREQ=WEEKLY;INTERVAL=2;BYDAY=MO,FR), consider adding WKST=MO when participants span the US (Sunday week start) and Europe (Monday week start), because crossing week boundaries changes which week belongs to the even interval!

Frequently Asked Questions

How do I write 'the last weekday of every month' in RRULE?
Use FREQ=MONTHLY;BYDAY=MO,TU,WE,TH,FR;BYSETPOS=-1, which selects all weekdays in the month and picks the final one.
Can I exclude a single holiday from an RRULE?
Yes. Add an EXDATE property on the VEVENT matching the exact DTSTART timestamp (and TZID) of the skipped occurrence.
Why can't I combine COUNT and UNTIL?
RFC 5545 explicitly defines COUNT and UNTIL as mutually exclusive termination bounds; include one or neither.
