Recover deleted calendar items
Applies To
Outlook for Microsoft 365
New Outlook for Windows
Classic Outlook
New Outlook
In the left folder pane of classic Outlook, select
Deleted Items
or
Trash
.
If you don't see the left folder pane, select the greater than (
>
) icon.
Find and select the calendar item to recover.
If you can't find the calendar item in
Deleted Items
, see
Recover deleted items from the server.
Select
Home
>
Move
>
Other folder
.
Calendar
should be highlighted. If not select it, then select
OK
.
Switch to
Mail
in new Outlook.
In the folder pane on the left, select
Deleted items
.
In the item list, select the event you want to recover.
On the
Home
tab, select
Restore
.
The item is restored to your calendar.
