"Allow Forwarding" option is missing from "Response Options" for a shared calendar Applies To Outlook for Microsoft 365 Last Updated: September 1, 2020 ISSUE Allow Forwarding is missing when you select Response Options for a shared calendar meeting. This occurs when Download Shared folder is not checked. STATUS:  FIXED This issue is fixed in Version 2008 Build 13127.20296. WORKAROUND Until you can get the fixed version use the following workaround: To work around this issue, please ensure Download Shared folder is checked for the shared mailbox.
